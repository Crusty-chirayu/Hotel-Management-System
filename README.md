## 📌 Overview

**Hotel Management System** is a lightweight, desktop-based application designed to simplify day-to-day hotel front-desk operations. It replaces manual registers and spreadsheets with a structured, GUI-driven workflow — helping staff manage customers, bookings, and room availability with fewer errors and faster turnaround.

Built entirely with **Java Swing** for the interface and **MySQL** for persistent storage, it runs fully offline on any machine with a local database — no internet dependency, no cloud costs.

| 📋 **Booking Overview** | View all bookings and customer details in a structured table |
| 🖥️ **Intuitive GUI** | Clean, user-friendly interface built with Java Swing |
| 💾 **Persistent Storage** | All data securely stored and retrieved via MySQL |

## 📋 Prerequisites

Before running the project, make sure you have:

- ☑️ **Java JDK 11+** installed
- ☑️ **MySQL Server** installed and running
- ☑️ An IDE — **NetBeans**, **Eclipse**, or **IntelliJ IDEA**

---

## 🚀 Installation & Setup

### Quick Setup in 5 Steps

**1. Clone the repository**
```bash
git clone https://github.com/Crusty-chirayu/Hotel-Management-System.git
```

**2. Open the project in an IDE**
Import the cloned folder into NetBeans, Eclipse, or IntelliJ IDEA as a Java project.

**3. Set up the database**
- Create a new MySQL database
- Import the provided database schema (`.sql` file) into it

**4. Configure the connection**
Update the project's database connection settings (host, port, username, password, and database name) to match your local MySQL setup.

**5. Run the project**
Open the `Main` class in your IDE and run it — the application window should launch immediately.
